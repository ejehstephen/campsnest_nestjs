# CampsNest 2.0

The modern student living, marketplace, and social connection superapp for Nigerian Universities. Discover verified housing, buy/sell student gadgets, and match with compatible roommates.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS & Lucide React
- **Backend & Auth**: Supabase (PostgreSQL, Auth, Storage)
- **Deployment**: Vercel
