# CampsNest 2.0 - Feature Roadmap

## Product Vision

Transform CampsNest from a seasonal student housing platform into a year-round student lifestyle platform.

The platform should give students reasons to return throughout the academic year.

---

# MVP DEFINITION

CampsNest 2.0 MVP should include:

✓ Authentication

✓ Student profiles

✓ Housing feed

✓ Housing details

✓ Marketplace

✓ Create marketplace listing

✓ Connect questionnaire

✓ Match discovery

✓ Basic messaging

✓ Privacy controls

✓ Reporting and blocking

The goal is to launch a usable version before adding complex features.

---

# SUCCESS METRICS

Track:

- Daily active users
- Weekly active users
- Marketplace listings created
- Housing views
- Connect questionnaire completion
- Matches created
- Messages sent
- Returning users

The most important metric:

Weekly active students.

CampsNest should become useful enough that students return regularly.
